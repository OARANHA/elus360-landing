# HyperFrames — acompanhamento comercial

Fonte editável da cena que acompanha a seção “Você não perde venda por falta de lead”: contato recebido → ELUS 360 → retorno agendado. Paleta institucional azul/ciano/violeta, mascote oficial, timeline GSAP determinística de 10s.

A própria página utiliza animação CSS equivalente em `lib/landing.ts` (ativa apenas na viewport e respeitando `prefers-reduced-motion`), sem necessidade de vídeo. A composição HyperFrames permite edição e renderização posterior.

Reprodução: `npm run dev`; validação: `npm run check`; vídeo: `npm run render`. **Não foram executados checks ou render HyperFrames nesta sessão.**
